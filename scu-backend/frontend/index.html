東吳學生新入口：Django 後端

這是佔位頁。前端網站（scu-portal-demo）改成呼叫 API 之後，執行 python manage.py sync_frontend --src ..\scu-portal-demo 就會用真正的入口網站取代這一頁。

可以直接點的 API

  • /api/profile：示範學生（王小明）
  • /api/programs、/api/departments?program=學士班、/api/classes?dept=資料科學系
  • /api/class-timetable?…資科三B
  • /api/courses?dept=資料科學系&grade=3、星期三下午我可以修的課
  • /api/events、/api/news
  • /api/selection/window（預覽 9/17 21:00）
  • /api/cart、/api/me/timetable
  • 前端相容格式：/api/bundle/courses（= real-courses.js）、/api/bundle/classes、/api/bundle/events
