# RULE-004 零股單位與買不起時的處理

## 1. 目的
規定紙上成交試算時，一檔要用幾股、買不起怎麼辦。

## 2. 適用範圍
`broker.py`／紙上隔日開盤成交；參數見 `config.py` 的 `PAPER_LOT_SIZE`。

## 3. 規則
1. 預設零股單位 **5 股**（`PAPER_LOT_SIZE`）。
2. 以該檔 `target_budget` 計價：先試買 5 股。
3. 5 股買不起 → 改試 **1 股**（真零股）。
4. 連 1 股（含手續費）也買不起 → **跳過該檔**，註記「單股也買不起」，預算留給同輪其他候補。
5. 不無限重排去硬塞高價股；單檔最多權益 20%。

## 4. 注意
手續費試算：約 0.1425%（最低 20 元）；賣出另計證交稅 0.3%。不是券商委託。
