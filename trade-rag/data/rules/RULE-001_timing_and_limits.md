# RULE-001 時序與硬限制

## 1. 目的
定義本紙上系統「什麼時候可以進場、什麼時候只能看」。

## 2. 適用範圍
`snr_backtest` 紙上帳戶與面板；不是券商真實下單。

## 3. 規則
1. 中期波段、使用日 K。
2. 訊號在 **t 收盤** 確認；成交在 **t+1 開盤**。
3. **盤中只預警、不成交**（`paper_alert.py` 破高提示）。
4. 總覽可看 **台指期夜盤**（大台近月，約 15:00–次日 05:00）：**只看盤，不進場**，不當 SNR 濾網。
5. 開盤漲停的買單視為買不到；開盤跌停的賣單留到隔日。
6. 最多同時約 5 檔；單檔最多權益 20%，不 all-in。

## 4. 注意
夜盤卡缺報價時不准用現貨加權假裝夜盤。
