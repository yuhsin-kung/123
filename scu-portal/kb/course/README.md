# kb/course — 課務類 RAG 知識來源（目前為空）

這個資料夾預計放「阿斯拉語言模型版」檢索用的**課務相關正式來源文件**，例如：

- 選課須知／選課註冊作業手冊（註冊課務組每學期公告）
- 學則及相關課務法規（加退選、期中退選、期末退修、學分上下限、擋修等）
- 學校行事曆（各階段選課、退選、退修期限）
- 各學系必選修科目表、畢業標準

## 放置原則

1. **只放學校正式公告的原始文件**（PDF、網頁存檔或轉成的純文字），不要自行改寫或編造法規內容。
2. 每份文件旁邊附一個同名 `.meta.md`（或在本 README 追加一行），記錄：來源網址、發布單位、學年度／學期、下載日期。
3. 過期版本移到 `archive/`，避免助手引用舊規定。
4. **不要把 `eval/` 的測試題或標準答案放進 `kb/`**，否則檢索會直接比對到題目文字，評估失真。

目前尚未放入任何文件；阿斯拉的關鍵字版回答中凡依賴正式規定者，都標示「待查證」。
