# 東吳學生新入口（黑客松示範）

> 所有課程、成績、日期、名額都是**示範資料**，不連接學校系統。

這是東吳大學 AI 黑客松提案的靜態網站原型。第二版依使用者回饋重新設計：**打開就先看到「今天的課」與「全校事務快到了」**，所有功能都做成**站內頁面**，不再跳去學校其他系統。

## 如何開啟

1. 直接雙擊資料夾中的 `index.html`（建議 Chrome 或 Edge；手機版面可用瀏覽器開發者工具的裝置模式看）。
2. 不需要安裝、不需要 npm、不需要建置，**完全離線**：沒有 CDN、沒有任何對外連線或外部連結。
3. 課表、選課車等資料存在這台電腦瀏覽器的 localStorage；「更多 → 示範設定」可以一鍵重設。

## 示範用的「今天」

首頁、課表、行事曆都以一個固定的示範時間計算，所以任何一天打開畫面都一樣好展示。

- 預設值：`js/config.js` 的 `SCU.DEMO_NOW = { date: '2026-09-30', time: '10:30' }`（星期三上午，正在上課、加退選剩 2 天）。
- 網址參數臨時覆寫（不用改程式）：

| 網址 | 畫面 |
|---|---|
| `index.html` | 9/30（三）10:30：第一堂上課中、下一堂 13:10 |
| `index.html?date=2026-09-30&time=13:00` | 午休，下一堂 10 分鐘後 |
| `index.html?date=2026-09-30&time=18:30` | 今天的課都上完了，提示明天第一堂 |
| `index.html?date=2026-10-03` | 星期六：今天沒有課 |
| `index.html?date=2026-10-09` | 國慶日補假：放假沒有課 |
| `index.html?date=2026-11-20&time=09:00` | 期中退選開放期間（可試「期中退選」頁） |

其他示範參數：

| 參數 | 效果 |
|---|---|
| `?demo=conflict` | 載入「衝堂＋額滿＋學分超過」的示範選課車並打開選課車 |
| `?demo=reset` | 清除本機資料，恢復初始示範課表 |
| `?asla=今天有什麼課` | 打開阿斯拉並直接提問（可重複多個 `asla=`） |

參數可以合併，例如 `index.html?date=2026-10-05&time=09:00&demo=reset#/timetable`。

## 頁面

| 頁面 | 路由 | 內容 |
|---|---|---|
| 首頁 | `#/home` | ①今天的課：時間、課名、教室、老師，標示「上課中」（含進度條）「下一堂・N 分鐘後」「已結束」；週末／放假／非上課期間顯示「今天沒有課」並提示下一個上課日。②全校事務快到了：進行中與即將到來的選課、繳費、考試、放假，含倒數天數，3 天內標紅。③四個捷徑 |
| 我的課表 | `#/timetable` | 週一～五 × 第 1–10 節格線，每門課顯示教室與剩餘名額，今天那欄標示；總學分、課程數、本週週次；課程清單；**查班級課表**（學制／系所／年級／班別，預設帶入登入學生） |
| 選課 | `#/course?tab=find` | 時段找課：星期＋節次起訖（上午／下午等快速鍵）、關鍵字、類別、只看有名額、只看不衝堂；每門課可「加選」或把課表中的課「退選」，卡片直接標示衝堂與額滿 |
| 選課車 | `#/course?tab=cart` | 異動清單 → 送出前檢查（衝堂／學分 16–25 示範規則／額滿，列原因並推薦替代課程：一鍵替換或加選）→ 送出後課表預覽（衝堂紅框、新加選虛線框）→「送出」：全部通過才能按，只存回本機課表並更新示範名額 |
| 成績 | `#/grades` | 累計 GPA（4.3 制示範換算）、累計平均、實得學分、最近系排；畢業學分進度（`?focus=grad`）；各學期 GPA 長條；所有學期成績卡同時顯示（平均、GPA、班排、系排、百分比、操行、各科等第）；本學期修課中 |
| 行事曆 | `#/calendar` | 列表（依月份分組、今天分隔線、倒數）與月曆（`?view=month&m=YYYY-MM`），可依類別篩選；與首頁共用同一份資料 |
| 更多（所有功能） | `#/more` | 依類別列出所有站內功能＋關鍵字搜尋；已完成的頁面直接前往，其餘進入站內「示範頁」 |
| 功能示範頁 | `#/p/功能代號` | 通用版型（說明、之後可辦理的項目、相關行事曆日期）；公告、校園信箱、學雜費繳費、期中退選、個人資料、諮商預約有專屬示範內容 |
| 示範設定 | `#/settings` | 切換示範日期時間（含常用情境按鈕）、重設示範資料、載入衝堂示範、顯示登入身分與資料來源 |
| 阿斯拉 | 每頁右下角 | 關鍵字版助手，所有答案只帶到站內頁面（見下方） |

導覽：手機底部分頁列「首頁／課表／選課／成績／更多」，桌機（寬度 ≥ 900px）改為上方導覽列（多一個「行事曆」）。

## 資料存取層（之後接 Python 後端）

之後課表資料會由「爬蟲 → SQLite → 小型 Python 後端」提供，登入學生的學制／系所／年級／班別會自動帶入查詢下拉選單。為了換資料來源時不用改頁面程式：

- **頁面程式（core.js、pages/*.js、asla.js）不直接讀 `data-*.js` 的全域變數**，一律呼叫 `SCU.DS.*`（`js/data-source.js`）。
- `DS.init()` 回傳 Promise，目前把本機示範資料放進快取；之後改成 `fetch('/api/...')` 即可，`main.js` 已經是等 `init()` 完成才渲染。
- 需要即時查詢的 `getClassTimetable()` 本身回傳 Promise，課表頁已用 `.then()` 處理，可直接換成 fetch。

| 函式 | 目前來源 | 建議未來 API |
|---|---|---|
| `getProfile()` | `profile.js` | `GET /api/profile` |
| `getCourses()`、`getCourse(code)`、`getPeriods()`、`getCreditRule()` | `data-courses.js` | `GET /api/courses`、`/api/periods` |
| `getMyTimetable()`、`saveMyTimetable(codes)` | localStorage（預設為示範課表） | `GET/PUT /api/me/timetable` |
| `getClassTimetable(學制, 系所, 年級, 班別)` | `data-classes.js` | `GET /api/class-timetable?program=&dept=&grade=&cls=` |
| `getClassOptions()` | `data-classes.js` | `GET /api/class-options` |
| `getEvents()`、`getEventTypes()` | `data-calendar.js` | `GET /api/events` |
| `getGrades()`、`getGpaScale()`、`getGradCredits()` | `data-grades.js` | `GET /api/me/grades` |
| `getFeatures()`、`getNews()`、`getMails()` | `data-features.js` | `GET /api/news`、`/api/me/mails` |
| `getCart()`／`saveCart()`、`getSeatDelta()`、`getWithdrawn()`、`resetMyData()` | localStorage | 依後端設計 |

注意：瀏覽器用 `file://` 開啟時不能 fetch 本機 API，接後端時請由 Python 後端（例如 Flask／FastAPI 的靜態檔案）提供這個資料夾。

## 阿斯拉（關鍵字版）

判斷順序（`js/asla.js`）：
1. **優先規則**：期中退選、「今天／明天有什麼課」（依示範今天與我的課表回答）、學分上下限、日期類問題（從行事曆找出對應事項並回答倒數）。
2. **時段找課**：「星期三下午有什麼課」「週五第 2 到第 4 節有什麼通識」→ 直接打開 `#/course` 並帶入條件。
3. **意圖關鍵字計分**：38 個意圖，每個都對應站內頁面。
4. 都沒命中 → 以字片段比對「所有功能」清單，再不行就建議到「更多」搜尋。

答案只含站內 hash 路由，不含任何外部網址。測試：`eval/questions.md`（在 Console 執行 `SCU.aslaAnswer('今天有什麼課')` 可快速檢查）。

## 哪些是示範資料

- 登入學生、全部課程（代碼、課名、教師、名額、教室）、班級課表都是虛構的。
- 節次時間、學分上下限 16–25、GPA 換算表、畢業學分 128 為示範規則，不是學校正式規定。
- 行事曆日期（加退選、繳費、期中退選、考試週等）為示範，不是學校公告。
- 成績、排名、操行、繳費金額、公告、信箱內容都是假資料。

## 注意

- 本原型不登入、不讀取、不傳送任何學校或個人資料；localStorage 只存在本機瀏覽器。
- 少數瀏覽器在 `file://` 下會停用 localStorage，此時網站仍可操作，但重新整理後會回到初始示範資料。
